# Sayarati Test App

This is the first test version of the Sayarati digital service booklet app.

Included features:
- Demo customer login
- English and Arabic switch
- Add customer car details
- Add service history records
- Save invoice photo name
- Shop button for `https://sayarati.online/`
- Mobile-friendly layout

This version saves demo data in the browser only. The next production step is
connecting customer accounts, cars, service records, and invoice photos to a
real online database.

## Netlify

This project is a static website. Netlify can publish it directly without a
build command.
