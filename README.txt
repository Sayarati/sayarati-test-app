Sayarati test app

To view the app:
1. Open this folder:
   C:\Users\cedri\Documents\New project 3

2. Double-click:
   index.html

What is included in this test version:
- Demo customer login
- English and Arabic switch
- Add car details
- Add digital service records
- Save invoice photo name
- Local demo storage in the browser
- Shop page that opens https://sayarati.online/ from the app

Shop note:
The browser test opens the shop in a new tab because sayarati.online blocks
normal iframe embedding. In the real mobile app, this screen should be built
as a native WebView so customers stay inside the app.

Important note:
This is a test/demo app. It saves data only on the same browser and computer.
The next step is connecting it to a real database, such as Supabase, so customer
accounts, cars, service records, and invoice photos are saved online.
